PUBBLICAZIONE SU GITHUB PAGES
1) Salva una copia del repository attuale.
2) Carica i file di questo ZIP nella radice del repository (sovrascrivi i file omonimi):
   index.html, styles.css, app.js, config.js, logo-dicette-mamma-header.png,
   logo-dicette-mamma.jpg, CNAME.
3) Esegui il commit. Attendi la pubblicazione, poi aggiorna il browser con Ctrl+F5.
4) Verifica il numero WhatsApp in config.js prima di pubblicare.
5) In config.js, GA4 è disattivo fino a corretta configurazione delle impostazioni privacy.

NOTE

DICETTE MAMMÀ — CODICE COMPLETO PER GITHUB PAGES

STRUTTURA
- index.html        homepage e catalogo completo, 3 prodotti
- styles.css        grafica e layout responsive
- app.js            SVG dei prodotti, finestra personalizzazione, carrello, WhatsApp
- config.js         numero WhatsApp e ID Analytics (opzionale)
- CNAME             dominio personalizzato esistente

INSTALLAZIONE SU GITHUB PAGES
1. Salva una copia del repository attuale prima di modificare i file.
2. Nel repository GitHub, sostituisci index.html e carica styles.css, app.js, config.js e CNAME nella cartella principale (root).
3. Se usi il metodo GitHub 'Add file > Upload files', trascina i file, non lo ZIP. Alla fine effettua Commit changes.
4. Non cambiare il file CNAME né i DNS se vuoi conservare www.dicettemamma.shop.
5. Apri il sito con Ctrl+F5, poi verifica da smartphone prodotti, personalizzazioni, carrello e invio WhatsApp.

ALTERNATIVA: UN SOLO FILE
Scarica Dicette_Mamma_INDEX_Tutto_In_Uno.html e rinominalo esattamente index.html.
In questo caso i file CSS e JS separati NON sono richiesti. Mantieni invece il CNAME.

PERSONALIZZAZIONI
- config.js: verifica whatsappNumber; ga4MeasurementId è vuoto per impostazione iniziale.
- app.js: modifica PRODUCTS per prezzi, descrizioni e nomi dei prodotti.
- Lo stesso numero WhatsApp è incorporato nell'alternativa tutto-in-uno.

COME FUNZIONA IL CARRELLO
Le scelte vengono conservate nel browser tramite localStorage.
Invia richiesta su WhatsApp apre un messaggio precompilato. Nessun pagamento, nessuna gestione server degli ordini; la richiesta arriva soltanto se il cliente preme Invia su WhatsApp.
I prezzi sono indicativi; spedizione non compresa. Le immagini dei prodotti sono mockup vettoriali indicativi, non fotografie reali.
Verifica gli adempimenti fiscali/commerciali e privacy prima di avviare vendite effettive.
